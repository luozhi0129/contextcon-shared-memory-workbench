Shared-Memory Workbench

Multi-agent shared-memory workbench — several agents and a user collaborate on one long task across days with zero re-briefing, on Meko as the context layer. Built for ContextCon: Remember Everything (YugabyteDB × HackerEarth).

The idea in one line

Every agent writes dated, compressed memory (facts / numbers / dates, auto-expiring) into one shared Meko datapack and runs context_search before starting work — so "where did we get to last time" is answered by the datapack, not by re-pasting context.

The honest result

At toy scale (5 memories, 3 traces) recall costs slightly more than re-pasting: 1,000 vs 830 tokens (−170, −20.5%). The saving appears as history grows — the re-paste baseline passes the recall level at ~7 memories (projection from measured per-unit costs). Every number traces to a run log in the repo.
